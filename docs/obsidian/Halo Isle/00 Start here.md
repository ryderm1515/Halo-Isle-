# Halo Isle — start here

> A third-person 3D island you explore in the browser. Wuhu Island's *feeling* (see something in the distance, go there), pushed into a tasteful **Frutiger Aero** look: turquoise water, glossy materials, golden-hour light, that optimistic early-2000s vibe.

**Play:** https://ryderm1515.github.io/Halo-Isle-/?v=2
**Code + full history:** https://github.com/ryderm1515/Halo-Isle-
**Controls:** WASD move · mouse look · Space jump (press again in the air for the glider) · Shift sprint · E interact · M map · Tab journal · Esc menu · 1–9 emotes

![[w2-0.jpg]]

## The project in numbers
- **9 days** (Nov 10 → Nov 18), **27 versions** pushed to GitHub
- **79 3D models**, all built in Blender by script · **62 textures** (Poly Haven CC0) · **9 real recorded sounds**
- **15 places** to discover · **17+ activities** with medals · **30 Sun Stars**, **5 halo shards**
- One character, animated entirely in code (no animation files)
