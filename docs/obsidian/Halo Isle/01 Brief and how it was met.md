# The brief, and how each part was met

The full original brief is in the repo at `references/BRIEF.md`. The short version, with what actually got built against each point:

| What the brief asked for | Where it stands |
|---|---|
| A fully explorable island inspired by Wuhu Island's *feel*, pushed toward tasteful Frutiger Aero | Built. Turquoise water, glossy jelly hero, aqua-gel UI, golden-hour grade. Original layout and names, nothing copied from Wuhu. |
| Distinct areas (town hall + shops, beaches, forest, mountain, waterfall, observatory, ruins, hidden spots), connected by paths and bridges | 15 named areas, footpaths, creek bridges, a pier, lifts, a mine line and a portal. Areas start hidden under cloud on the map and reveal as you find them. |
| A big central mountain with a mysterious halo visible from anywhere | Halo Peak with the ring of light; it's the story's centre (5 shards restore it). |
| Not a walking simulator: Wii Sports Resort-style mini-games, plus environmental puzzles and a light story | 17+ activities with medals, a ruins gate puzzle, the glyph-block arch, shards and stars. The story never blocks play. |
| A lovable main character that matches the sheets, with "Nintendo levels" of personality | Modelled in Blender from the character sheet, rigged, and animated entirely in code (springs, squash and stretch, planted feet, leaf lag, emotes). Several rounds of fixes from my feedback (arms that looked like wings, running too fast). |
| Interactive, reactive world | Grass and flowers bend around you, splashes, beach balls with physics, wobbling objects, cats you can befriend, birds and gulls, kites, wind gusts. |
| Real Blender models and a real asset pipeline (Poly Haven, ambientCG, Kenney, Quaternius), exported as GLB and tested in the game | Every model is generated by Blender Python scripts in `pipeline/blender/` and exported to GLB. Terrain textures are Poly Haven CC0; sounds are real CC0/public-domain recordings (sources logged in `LICENSES.md`). |
| Smooth camera and controls, satisfying jump | Third-person spring camera, sprint, slide, triple jump, long jump, glide. |
| Clean Frutiger Aero UI that feels like a game, not a dashboard | Glassy gel HUD, title screen, journal, wardrobe, painted island map with custom icons. |
| Polish one area first, then build outward | That's how it went: hero + plaza first (Nov 10), then the loop, then outward. See [[02 Phases and iterations]]. |

**Addendum (Nov 10):** the point is to explore and have fun, with progression through activities, secrets and cosmetics, and a mystery underneath. Medals, the free wardrobe, hidden areas and the shard story cover this.
